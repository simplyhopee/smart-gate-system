# smart-gate-system

A beginner-friendly Arduino smart gate system that uses a servo motor and push button to simulate an automated gate. The project demonstrates basic robotics concepts, including motor control, digital inputs, and automation logic.

## Features
- Opens the gate when the button is pressed
- Closes the gate automatically
- Uses a servo motor to simulate gate movement
- Simple automation logic
- Beginner-friendly robotics project

## Components Used
- Arduino Uno
- Servo Motor
- Push Button
- Breadboard
- Jumper Wires

## Skills Demonstrated
- Arduino programming
- Servo motor control
- Digital input reading
- Conditional statements
- Embedded systems fundamentals
- Robotics automation concepts

## How It Works
1. The system waits for a button press.
2. When the button is pressed, the servo rotates to open the gate.
3. After a short delay, the servo returns to its original position to close the gate.
